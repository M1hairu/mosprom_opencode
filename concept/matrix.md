# Матрица записки: требования слайда 9 и критерии слайда 16

Задача #33. Файл — источник для `make note`. Сборка читает таблицы ниже и печатает их в
приложении к `pitch/note.pdf`.

Как читать:

- «Раздел» — код из таблицы «Разделы записки». Несколько кодов — через запятую. «—» —
  требование закрывает не записка (например, презентация).
- «Где» — пункт раздела: «§2.1» — заголовок «2.1» в файле раздела. Сборка ищет такой
  заголовок и пишет предупреждение, если его нет.
- «Статус» — «закрыто» или «в работе #N». Нет файла раздела — сборка сама ставит
  «в работе #N» по задаче раздела. Статус «закрыто» ставит человек, когда пункт есть в тексте.
- Текст требований — дословно из `task/case.md` (слайды 9 и 16), иногда короче.
