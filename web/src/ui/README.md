# web/src/ui — UI-основа

Токены, базовые компоненты и оболочки поверхностей (#54). Стиль — как на lassard.ru
(жюри разрешило шрифты и фото ЛАССАРД, 24.10), палитра — `task/brandbook.md`.
Цвета: белый, красный `#DD191C`, графит `#26262E`; светлые станки — на графитовой витрине.

## Файлы

| Файл | Что внутри |
|---|---|
| `tokens.css` | Цвета (с. 27 + оттенки lassard.ru), Inter (текст) и Montserrat (заголовки), отступы, скругления, паттерн (с. 29). Глобальный, подключён в `main.tsx`. |
| `components.tsx` | `Logo`, `Button`, `Card`, `PageTitle`, `EmptyState`, `OfflineBanner`, `useOnline`, `TabBar`. |
| `shells.tsx` | `PhoneShell` (`/guide`), `ScreenShell` (`/screen/:zone`), `DesktopShell` (`/planner`). |
| `icons.tsx` | Иконки вкладок гида, 24 × 24, цвет — от текста. |
| `fonts/` | Montserrat 400–800 и Inter 400–600, кириллица и латиница. Лицензии — `fonts/OFL.txt`, `fonts/OFL-Inter.txt`. |

## Правила

- Цвет, шрифт и отступ берите только из переменных `tokens.css`.
- На экране одно главное действие: `Button` без `variant` (красная кнопка lassard.ru).
  Остальные кнопки — `variant="secondary"` (графитовая рамка на белом).
- Кнопка не ниже 44 px: токен `--touch` = 48 px.
- `TabBar` принимает не больше 5 вкладок. Иначе компонент бросает ошибку.
- В шапке каждой оболочки логотип и красная кнопка «На главную» ведут на главную (#352).
  Тема одна — «Оптика»: `data-theme="optic"` в `index.html`, стили — `themes/optic.css`.
- Оболочка занимает всё окно. Прокрутка — внутри области содержимого.
  `ScreenShell` не прокручивается: размеры в `vh`.
- Логотип — только цветной на белом фоне (с. 25). Не меняйте его пропорции и цвет (с. 26).
