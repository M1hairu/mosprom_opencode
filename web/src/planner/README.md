# web/src/planner — 3D-план `/planner`

План зала 219 в 3D (Three.js). Код перенесён из pochta.
Страница — `web/src/pages/Planner.tsx`. 3D-вид — на всё окно под шапкой; 2D, правки и
боковой панели нет (#353). Прогулки от первого лица и `/tour` нет (#395, #396).

## Формат

План — PlanDocument v1 pochta (`model.ts`). Метры, X вправо, Y вверх, поворот по часовой.
Поля ЛАССАРД лежат в `extensions` (план) и `attributes` (зоны, объекты).

## Данные — `source.ts`

| Функция | Что делает |
|---|---|
| `loadConceptPlan()` | концепция `content/plan-219-zoned.json`: зоны и экспонаты |

Проверку норм делает сервер (`POST /api/validate`, `make eval`); страница её не вызывает.

## 3D-модели экспонатов — `models.ts`, `models.json` (#354)

- Таблица `models.json`: ключ — id объекта или id типа, значение — файл в `web/public/models/`.
  Id объекта главнее id типа. `make models` (`scripts/fetch_models.py`) кладёт сюда *.glb из
  релизов GitHub: имя файла — ключ. Сжатие Draco и meshopt не поддерживаем: такой файл пропускается.
- Значение — имя файла или `{file, scale}`. Модели v5 (релиз `3d-assets-v5-2026-10-24`) — в метрах:
  `scale` 1 — натуральный размер, 0.2 — миниатюра 1:5. Под моделью — белая подставка до верха
  коробки плана: витрина или подиум (#396). Без `scale` модель вписана в коробку плана.
- Модель встаёт в центр объекта, на его базу, с его поворотом.
- Модель грузится после коробок. Загрузилась — коробка скрывается. Ошибка — коробка остаётся,
  в консоли предупреждение. Объект с находкой проверки остаётся цветной коробкой.
- Холст хранит число показанных моделей в `data-models`, картинок — в `data-screens`.

## Экраны и цвета (#369)

- Панели и экраны показывают рендеры `web/public/renders` (`SCREENS`, `models.ts`) на обеих
  длинных сторонах. Картинка не загрузилась — панель без неё, в консоли предупреждение.
- Стены и мебель экспозиции — белые, техника — серая (эксперт ЛАССАРД, #335). Цвета зон
  на полу — яркие.
- Сенсорный экран: не больше 1,5 пикселя на точку, ради частоты кадров.
